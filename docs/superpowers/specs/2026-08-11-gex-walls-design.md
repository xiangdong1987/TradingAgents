# 日报期权面升级：GEX + Call/Put Wall + 方向标签

日期：2026-08-11 ｜ 状态：已落地（2026-08-11）

## 背景与目标

多空行现有的期权数据只有最近到期的 P/C 比，信息量有限。升级为期权面
三件套（GEX、Call Wall、Put Wall），并让日报据此给**每只票固定格式的
方向标签**。已实测可行：NVDA 30 天内 4 个到期 400 张合约 1 秒拉完、
IV 全有值，GEX −740M$/1%、Call 墙 225、Put 墙 215（现价 217.55）。

原则不变：Python 算数字，LLM 只解读。

## 1. 数据层 —— `get_positioning` 升级（`assistant/quotes.py`）

期权部分从「最近一个到期」扩展为「**到期日 ≤ 今天+30 天的链聚合，
最多取前 6 个到期**」。返回 dict 新增三个可选键（做空三键不动）：

- `gexMUsd`（float，百万美元/1%）：净 Gamma 敞口。逐张合约：

  ```
  Γ = φ(d1) / (S·σ·√T)，d1 = [ln(S/K) + 0.5σ²T] / (σ√T)   # r=0 简化
  贡献 = Γ × OI × 100 × S² × 0.01，calls 记正、puts 记负
  gexMUsd = round(Σ贡献 / 1e6, 0)
  ```

  符号约定是行业惯例的 naive 做市商假设（做市商持有客户卖出的仓位：
  多 call 空 put），spec 明示这是近似而非真实持仓。
- `callWall` / `putWall`（float）：聚合 OI 最大的 call / put 行权价。
- `pcOi` / `pcVol` 改为**跨到期聚合**口径（原来只算最近到期）——口径
  变化，既有测试期望值可能要按聚合语义调整。

实现细节：

- 现价 S 取 `info` 的 `regularMarketPrice`，缺则 `previousClose`；
  两者都缺 → 期权键全部不写（做空键不受影响）。
- T = max(距到期自然日/365, 1/365)；IV ≤ 0 或缺失的合约跳过（不计入
  GEX，但 OI 照常计入墙与 P/C——墙只看 OI 不需要 IV）。
- 单个到期链拉取失败跳过该到期；全部失败 → 期权键不写。
- 既有契约不变：至少一键才返回 dict、ISIN/.MI/.DE 直接 None、绝不抛出。

## 2. 日报 —— 期权面行 + 方向标签（`assistant/daily_brief.py`）

- 每只票在「多空:」行之后加一行（三键齐才写完整；部分缺就只写有的段；
  全缺不写此行）：

  ```
  期权面: GEX -740M$（负Gamma）· Call墙 225 · Put墙 215
  ```

  GEX 括注：`正Gamma` / `负Gamma`（按符号）。
- 口径说明追加：`期权面口径：GEX 为做市商净 Gamma 敞口（正 = 对冲盘
  压波动、区间倾向；负 = 助涨助跌、易加速）；Call 墙为最大阻力位、
  Put 墙为最大支撑位；负 Gamma 且跌破 Put 墙是加速下行信号。数据为
  30 天内期权链聚合。`
- 结构指示追加：`持仓点评与自选分析里，每只美股结尾给固定方向标签之一：
  【偏多】【偏空】【区间震荡】【高波动警惕】+ 一句理由（综合期权面、
  资金流、做空与新闻）；无期权数据的标的（意/德股、国债）只按资金流与
  新闻给标签，依据不足时写【数据不足】，不要硬编。`
- **大盘行**：`# 股指期货` 块末尾追加一行（`fetch_positioning("SPY")`
  取数，取不到就不写）：

  ```
  SPY 期权面: GEX +1200M$（正Gamma）· Call墙 580 · Put墙 560
  ```

## 3. runner 与 App

- runner 零改动（沿用 `fetch_positioning` 透传，生产走真实现）。
- App 零改动（日报 markdown 渲染）。

## 4. 成本

每只美股期权链调用 1 → ≤6 次；当前 ~10 只美股 + SPY ≈ 66 次/天，
日报 job 内多花 30-60 秒。无新依赖（math 标准库）。

## 不做

- 零 Gamma 翻转位（zero-gamma flip）——一期先不算，读法教给 LLM 的
  正负号已够用，要时再加
- 盘中刷新（日报一天一次的粒度不变）
- 意/德股期权面（数据源无）

## 测试

- quotes：BS gamma 手算 fixture（构造单张合约验公式）；多到期聚合的
  GEX 符号与量级；墙位 = 聚合 OI 最大 strike；IV 缺失合约不计 GEX 但
  计入墙；现价缺失 → 期权键全不写、做空键保留；单到期失败跳过；
  30 天窗口与 6 链上限；既有 P/C 测试按聚合口径更新
- daily_brief：期权面行完整/部分/缺失三态；口径说明与方向标签指示进
  prompt；SPY 行存在与降级；既有测试注入的假 `_posi` 补新键后断言更新
- 两端全量回归全绿（App 无改动，跑 Flutter 只为确认零回归）
